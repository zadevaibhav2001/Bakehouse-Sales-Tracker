# Logo Setup

To display "The Bake House" logo in the website:

1. Save your logo image as `logo.png` in this directory (`frontend/images/`)
2. The logo will automatically appear in the navbar
3. Recommended size: 500x500 pixels or larger (square format works best)

The logo will be displayed with:
- White circular background
- 70px height/width
- Subtle shadow effect
- Centered in the navbar

If the logo doesn't appear, check:
- File name is exactly `logo.png` (case-sensitive)
- File is in the correct directory: `frontend/images/logo.png`
- Image format is PNG (recommended for transparency)
